# training-planner
Костюк Анастасия
**Описание:**  
Приложение для планирования тренировок с графическим интерфейсом (Tkinter).  
Позволяет добавлять тренировки с указанием даты, типа и длительности, фильтровать записи по дате и типу, сохранять и загружать данные в формате JSON.
## Функциональные возможности
- Добавление тренировки (проверка корректности даты и длительности)
- Отображение списка тренировок в таблице
- Фильтрация по типу тренировки
- Фильтрация по конкретной дате
- Сброс фильтров
- Автоматическое сохранение данных в файл `trainings.json`
- Загрузка сохранённых данных при запуске
## Примеры использования
**Тест 1. Добавление корректной тренировки**  
1. В поле "Дата" введите `2025-04-24`  
2. Выберите тип `Бег`  
3. Введите длительность `45`  
4. Нажмите "Добавить тренировку"  
→ В таблице появится строка с этими данными.
**Тест 2. Ошибка при неверном формате даты**  
1. Введите дату `24.04.2025`  
2. Нажмите "Добавить тренировку"  
→ Появится сообщение об ошибке "Неверный формат даты!".
**Тест 3. Фильтрация**  
1. Добавьте несколько тренировок разных типов  
2. В фильтре по типу выберите `Плавание` и нажмите "Применить фильтр"  
→ В таблице останутся только тренировки с типом "Плавание".

**Тест 4. Сохранение данных**  
1. Добавьте любые тренировки  
2. Закройте приложение  
3. Откройте снова  
→ Все добавленные тренировки появятся в таблице (данные загружены из `trainings.json`).
